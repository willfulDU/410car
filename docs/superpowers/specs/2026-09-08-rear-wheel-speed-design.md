# 后轮轮速采样设计

**状态：** 已由用户确认，待复核文档后实施。

## 目标

车端主 ECU 对两台后轮电机回传的 FG 脉冲独立计数、测频并换算为左右后轮转速（RPM），在现有 SSD1306 中控屏上清晰显示。现有的遥控、档位、电机、转向和灯光行为保持不变。

## 已确认硬件条件

- 左右两台电机各有一根黄色 FG 线；电机资料规定 FG 为 NPN 开集电极输出，每个电机轴转一圈产生 18 个脉冲。
- 固定接线由现有 `User/motor/motor.c` 注释和参考工程确认：`PA1` 是 Motor2 的测速输入，`PA2` 是 Motor1 的测速输入。
- 参考车的实测左右映射为 `PA1 -> 左后轮`、`PA2 -> 右后轮`；将映射保留为单一配置宏，方便上车用单轮转动复核。
- 后轮直径为 60 mm。它不改变 RPM 换算，本次只记录为后续车速换算的车辆参数，不在中控屏增加线速度字段。
- 当前定时器已分别用于 TIM1 电机 PWM、TIM2 延时、TIM4 舵机 PWM。PA1/PA2 也不具备可用的双路定时器捕获映射，因此使用 EXTI 软件计数。
- `wheel.c` 与 `pedal.c` 虽使用 PA1/PA2 的 ADC 通道，但仅在方向盘 ECU 分支初始化；车端主 ECU 不会与测速输入冲突。

## 架构

新增 `User/wheel_speed/`，分离纯计算和 STM32 硬件访问：

1. `wheel_speed_calc.c/.h` 是不依赖 STM32 头文件的 RPM 换算、滤波和固定宽度文本格式化模块，可在主机侧测试。
2. `wheel_speed.c/.h` 负责 PA1/PA2 GPIO 与 EXTI 初始化、脉冲累计、采样窗口以及左右映射。中断服务程序也放在此模块，避免不编译测速模块的测距 ECU 产生未定义引用。
3. `main.c` 只初始化模块、在主循环调用更新，并以受节流的方式显示最新左右 RPM。
4. Keil 工程加入两个新的 C 源文件与 `User/wheel_speed` 包含目录。

## 脉冲采样

`WheelSpeed_Init()` 将 PA1 和 PA2 配置为 `GPIO_Mode_IPU`，把它们映射到 EXTI1 与 EXTI2，并使用上升沿触发。内部上拉为开集电极 FG 信号提供逻辑高电平；硬件接线不变。

`EXTI1_IRQHandler()` 和 `EXTI2_IRQHandler()` 只做两件事：清除对应 pending 位，给相应一侧的 `volatile uint32_t` 累计计数器加一。单通道 FG 信号只能表示转速大小，倒挡时仍显示正的 RPM；方向继续由已有 D/R/N 逻辑表示。

主循环每次调用 `WheelSpeed_Update()`。模块根据 `SysTick_GetTick()` 的绝对毫秒时间判断 250 ms 窗口是否结束，读取累计值与上次快照之差，并按实际经过时间换算：

```text
rpm = pulse_delta * 60000 / (pulses_per_wheel_rev * elapsed_ms)
```

使用实际窗口长度而不是假定主循环固定周期，可以避免 NRF24L01 接收阻塞造成的测速误差。结果经过 alpha=1/2 的一阶低通滤波，降低窗口边界的跳变；零脉冲自然得到 0 RPM。

## 标定与配置

初始配置采用同款参考车的上板实测值：

```c
#define WHEEL_SPEED_PULSES_PER_REV  398U
#define WHEEL_SPEED_WINDOW_MS        250U
#define WHEEL_SPEED_SWAP_SIDES       1U
#define WHEEL_SPEED_DIAMETER_MM      60U
#define WHEEL_SPEED_CALIBRATE        0U
```

`398` 是每个后轮转一圈的脉冲数，已包含减速比，因此不应直接把电机资料中的 `18` 当作后轮每圈脉冲数。为消除个体减速比或左右映射差异，提供标定模式：抬起后轮，记录累计脉冲，手推单侧后轮正好 10 圈，再用差值除以 10 更新 `WHEEL_SPEED_PULSES_PER_REV`。单独转左/右轮也可验证 `WHEEL_SPEED_SWAP_SIDES`。

## 中控显示

保留开机组号、日期、档位和转向灯显示。第 4 行每 250 ms 更新为：

```text
L:1234 R:1234
```

其中左右数值均为后轮 RPM，采用四位右对齐格式；0 显示为 `   0`，超过 9999 显示 `----`。显示函数只在内容变化时重画该字段，避免软件 I2C 刷新占用主控制循环。

标定模式下，第 4 行改为两侧累计脉冲数，便于不使用示波器完成接线与系数确认。

## 错误处理与限制

- 换算函数必须保护零窗口和零脉冲系数，返回 0，不能除零或溢出。
- RPM 运算使用 64 位中间值，并饱和到 9999，避免异常脉冲造成回绕或虚假的数值。
- 中断计数器使用 32 位无符号累计和减法，以正确处理计数器回绕。
- NPN FG 信号若存在毛刺会造成读数偏高；本功能不伪造软件消抖，异常时优先检查信号电平、接地和必要的硬件滤波。
- WS2812 的 SPI 数据发送区必须短暂屏蔽中断，避免新的 EXTI 处理打断灯带时序；临界区仅覆盖实际 SPI 突发传输。

## 验证

实施时采用测试优先：

1. 先在主机测试中证明 RPM 换算、舍入、滤波、格式化、零除保护及饱和行为。
2. 再检查主循环初始化/更新、PA1/PA2 EXTI 配置、Keil 文件清单和显示接入。
3. 编译接收端与方向盘端配置，要求 0 error、0 warning。
4. 上车先启用标定模式，架空后轮，确认单独转动一侧时只有对应累计值增加；随后标定每轮脉冲数、确认左右显示和松油门归零。
