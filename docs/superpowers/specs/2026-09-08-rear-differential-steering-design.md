# 后轮差速转向设计

**状态：** 已由用户确认，待用户审核本文档后编写实现计划。

## 目标

基于已完成的左右后轮 RPM 采样，为双后驱小车增加后轮差速转向。方向盘输入决定前轮等效转角，油门决定整车中心线目标转速；控制层据此生成左右后轮的独立目标 RPM，并通过独立速度闭环调节两路 PWM。

本设计不改变 D/R/N 的公共方向控制，也不将转向灯输入作为转向控制信号。

## 已确认几何与标定粒度

| 参数 | 数值 | 用途 |
| --- | ---: | --- |
| 轴距 L | 199.99 mm | 后轴中心至等效前转向轴中心 |
| 后轮距 T | 101.78 mm | 两个后轮轮心距 |
| 后轮半径 r | 30 mm | RPM 与线速度换算 |
| 最大等效前轮转角 | ±30° | 查表范围 |
| 转角表格粒度 | 1° | 共 31 个转角行 |
| 踏板表格粒度 | 10% | 共 11 个踏板列 |

轮胎半径不影响左右轮 RPM 比，只用于线速度换算：

```text
v_center_mps = n_center_rpm × 2π × 0.03 / 60
             = n_center_rpm × 0.00314159
```

## 运动学

采用低速、无侧滑的 Ackermann/自行车模型。令 \(\delta\) 为前轮等效转角绝对值，\(n_c\) 为后轴中心的目标 RPM：

```text
R = L / tan(|δ|)
d = (n_outer - n_inner) / n_c = T / R = (T / L) × tan(|δ|)

n_inner = n_c × (1 - d / 2)
n_outer = n_c × (1 + d / 2)
ratio_outer_inner = (1 + d / 2) / (1 - d / 2)
```

左转时左后轮为内轮、右后轮为外轮；右转时反过来。倒车仍使用同一侧的内外轮关系，仅由既有 H 桥方向命令改变两台电机的旋转方向。

## 固件数据流与边界

```text
方向盘 ADC ─→ 转角标定/查表 ──────┐
                                    ├─→ 左右目标 RPM ─→ 两个速度 PI ─→ Motor1/Motor2 PWM
踏板 ADC ───→ 踏板→中心 RPM 查表 ─┘
后轮 FG RPM ─────────────────────────→ 两个速度 PI 的反馈
D/R/N ───────────────────────────────→ 公共 H 桥方向/停车仲裁
```

- 方向盘 ADC 到等效前轮转角的映射必须单独标定；现有 `map_wheel()` 的 ADC/舵机脉宽范围不能直接等同于实际转角。
- 每轮闭环使用对应一侧的 RPM 反馈。当前接线/标定约定为 Motor2/PA1 为左后轮、Motor1/PA2 为右后轮；上车前仍需抬轮复核。
- 反馈无效、无线帧无效、N 档、零踏板或换向过程必须输出双电机 0 PWM。
- 目标转速与 PWM 均限幅；推荐每 10 ms 控制一次，目标差速使用斜坡，防止方向盘突变时扭矩跳变。
- 先在架空后轮状态验证左右映射、正反转、内外轮快慢关系和查表边界，再进入低速实车测试。

## 验证标准

1. 直行或 0° 输入时，两个目标 RPM 相同。
2. 左转时右后轮目标 RPM 大于左后轮；右转相反。
3. 在 30°、100% 踏板时，外/内轮目标 RPM 比为 1.3444，差速为 29.38% × N100。
4. 改变 D/R/N 只影响电机共同方向；同一转角下的左右 RPM 绝对值目标关系不变。
5. 单独施加负载后，独立 PI 使两侧实际 RPM 分别收敛到各自目标，而不是仅维持 PWM 比。
