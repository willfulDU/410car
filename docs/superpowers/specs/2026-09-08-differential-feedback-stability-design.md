# 后轮差速反馈稳定性设计

**状态：** 已确认，待用户审核本文档后编写实现计划。

## 问题与根因

实车和 OLED 都观察到一侧约 100 RPM、另一侧停止。这不是目标差速表直接生成的结果：现有几何表在中心目标 100 RPM、满转向时只会请求约 85/115 RPM。

根因是反馈与控制周期不匹配。轮速每 250 ms 更新一次，但 PI 每 10 ms 使用同一个轮速样本更新 25 次；积分在旧数据期间迅速饱和，使一侧 PWM 被压为 0、另一侧升高，形成振荡。

## 已确认目标

1. 仅在得到新的左右轮 RPM 样本时执行一次闭环校正；当前采样周期为 250 ms。
2. PWM 的基准值来自当前踏板 PWM，并按左右目标 RPM 比例分配；闭环只提供有限幅的增减量。
3. 左右目标转速差不得超过中心目标转速的 15%。
4. 未获得两侧新鲜反馈时，沿用现有低占空比起步和失效停车策略。
5. 无线失联、N 档、零踏板、换向和反馈失效仍必须输出双电机 0 PWM 并清空控制状态。

## 数据流与控制策略

```text
踏板 PWM + 受限后的左右目标 RPM ──→ 每侧前馈 PWM ──┐
                                                       ├─→ 限幅后 PWM ─→ 左右电机
每 250 ms 一次的左右 RPM 新样本 ─→ 每侧 PI 微调 ─────┘
```

### 目标转速限制

保持现有几何查表和内外轮判定，但在 `DifferentialSteering_BuildTargets()` 中将总目标差速限制为：

```text
difference = min(geometry_difference, center_rpm × 150 / 1000)
```

15% 是总差速 `(outer - inner) / center` 的上限，而非单侧相对中心的上限。整数分配继续使用现有的中心对称取整方式；最多存在 1 RPM 的取整误差。

### 前馈与反馈微调

对每一侧计算：

```text
base_duty = pedal_duty × side_target_rpm / center_target_rpm
final_duty = clamp(base_duty + correction, 0, 100)
```

`correction` 只在轮速产生新样本时更新，使用该侧的 `target_rpm - measured_rpm` 计算，并限制在 `-8` 至 `+8` 个 PWM 百分点。积分同样只在新样本时累计；当微调已到上下限且误差继续把它推向限位时，不再向该方向积分（抗积分饱和）。两次样本之间保持上一次 `final_duty`。

首版使用 `Kp = 10/100`、`Ki = 1/100`（单位为每个 250 ms 样本）和 ±8 个 PWM 百分点限幅；这些量定义为集中可调常量。若架空轮或低速实车测试出现持续偏差，仅在采样事件内调整这些常量，不改变上述安全边界或采样机制。

### 新样本事件

`WheelSpeed_Update()` 改为返回“本次是否完成一个 RPM 采样窗口”。主循环仍可持续处理无线、灯光和安全状态，但只有在两侧反馈新鲜且该函数报告新样本时，才调用差速闭环更新。这样控制器不会对同一轮速重复积分。

## 接口变化

- `WheelSpeed_Update()` 返回 `uint8_t`，新 RPM 样本发布时返回 `1`，其余时间返回 `0`。
- 差速控制更新接口增加踏板基准 PWM 参数，输出前馈加闭环微调后的左右 PWM。
- 差速模块新增总差速上限和 PWM 微调限幅常量；几何转向映射、左右轮接线交换选项保持不变。

## 验证

### 自动化

1. 满转向、中心 100 RPM 的左右目标差不超过 15 RPM（允许 1 RPM 的整数取整误差）。
2. 任意转向都不会生成超过 15% 上限的总差速；直行仍生成相同目标。
3. 没有新的轮速样本时，控制状态和输出 PWM 不变化；一个新样本只触发一次积分。
4. 正、负误差下的 PWM 微调均不越过设定限幅；停车或失效时控制状态清零、PWM 为 0。

### 硬件

1. 架空后轮：逐渐加踏板并打满转向，OLED 两侧 RPM 都持续非零；左右之差不超过中心转速的约 15%。
2. 低速直线：两侧 RPM 接近且不出现周期性 0/满 PWM 跳变。
3. 低速左右转：外侧 RPM 高于内侧，但两侧持续转动；方向切换时内外侧关系保持正确。
4. 拔掉任一 FG 或停止无线帧：在现有超时内双电机停车。
